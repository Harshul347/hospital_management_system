# Hospital Patient Management System

## About the Project
A C++ based application designed to manage basic hospital patient records and organize patient-related information.

## Features
- Add patient records
- Display patient information
- Search for patients
- Update or manage records, if implemented

## Technologies Used
- C++
- Object-Oriented Programming
- Data Structures

## Concepts Used
Classes, objects, functions, loops, and conditional statements.

## How to Run
1. Open the source code in VS Code.
2. Compile the C++ file.
3. Run the executable and follow the menu.

## Learning Objective
To understand how programming can help organize hospital records.
